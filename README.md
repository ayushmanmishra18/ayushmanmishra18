## 🚀 Featured Projects

### 💼 SalesPilot CRM

**Multi-Tenant B2B Sales CRM**

React 19 · TypeScript · Node.js · Express · MongoDB · Redis · Socket.IO · BullMQ

* Multi-tenant CRM for contacts, deals, pipelines, activities, documents and analytics
* JWT authentication with rotating opaque refresh tokens and reuse detection
* Real-time collaboration using Socket.IO and Redis pub/sub
* Background SLA processing using BullMQ
* Idempotency-key handling to prevent duplicate writes during retries
* Deployed using Vercel, Render, MongoDB Atlas and Upstash Redis

---

### 📊 PortfolioPulse

**Multi-Tenant B2B Portfolio Management SaaS**

React 19 · TypeScript · Express · MongoDB · REST · JWT · API Keys

* Multi-tenant platform for managing portfolio assets and organizations
* Strict tenant-level data isolation
* Fault-tolerant webhook delivery with HMAC-SHA256 signing
* Automatic retry with exponential backoff
* JWT-secured internal APIs and API-key authenticated external APIs
* API rate limiting and usage tracking
